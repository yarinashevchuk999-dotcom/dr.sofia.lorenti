# DR. SOFIA LORENTI — статична версія

Готова статична збірка сайту (dark-gold версія) для здачі домашнього завдання.
**Не потребує Node.js, Next.js, збірки чи localhost.**

## Як відкрити

Просто відкрийте `index.html` у браузері (подвійний клік).

Для 100% коректного відображення (деякі браузери обмежують `file://`)
рекомендується відкрити через будь-який простий сервер, напр.:

```
npx serve .
```

…і зайти на адресу, яку він покаже.

## Що всередині

| Файл | Призначення |
|---|---|
| `index.html` | Уся розмітка сторінки |
| `styles.css` | Скомпільований CSS (Tailwind + усі кастомні стилі та анімації) |
| `app.js` | Вся інтерактивність: мова UA/EN/IT, інтро-екран, плавний скрол, scroll-reveal, паралакс, hero-анімація, карусель відгуків, акордеон FAQ, перефарбування портрета, поп-ап запису на консультацію |
| `assets/` | Усі зображення (фото лікарки, 8 фото процедур, фото для контактів) |
| `_input.css` | Вихідний файл, з якого зібрано `styles.css` (не потрібен для запуску) |

## Збережено без змін

Темна золота тема, структура, тексти (тримовність UA / EN / IT), шрифт (Jost
через Google Fonts), усі анімації — інтро-«вмикання» екрана, живий золотий
контур рамок, scroll-driven поява секцій, кінематографічний reveal хіро-блоку,
паралакс, плівкове зерно, мікро-взаємодії кнопок, кросфейд при зміні мови,
шахівниця фото/текст у секції "Процедури", поп-ап запису на консультацію.

## Заявки з форм (поп-ап запису + форма в "Контактах")

За замовчуванням форми просто показують "Дякую!" локально — нікуди нічого не
надсилається. Щоб заявки падали в Google Таблицю, відкрийте `app.js`,
знайдіть на початку файлу рядок

```js
var GOOGLE_SHEETS_WEBHOOK_URL = "";
```

і вставте туди URL вашого Google Apps Script Web App (той самий, що
налаштований для основного Next.js-сайту).

## Зовнішні залежності

Google Fonts (`fonts.googleapis.com`, шрифт Jost) і Cloudinary (hero-відео).
Потрібне інтернет-з'єднання під час відкриття. Усе інше (CSS, JS,
зображення) — локальне.
